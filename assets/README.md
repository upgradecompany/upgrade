# Assets Folder

Place your app icons and images here.

## Required Files (for publishing)

### icon.png
- Size: 1024x1024 pixels
- Format: PNG with transparency
- Purpose: App icon shown everywhere

### splash.png
- Size: 1284x2778 pixels (or larger)
- Format: PNG
- Purpose: Loading screen when app opens

### adaptive-icon.png (Android only)
- Size: 1024x1024 pixels
- Format: PNG
- Purpose: Android adaptive icon (foreground layer)

### favicon.png (Web only)
- Size: 48x48 pixels minimum
- Format: PNG or ICO
- Purpose: Browser tab icon

## Creating Your Icons

### Free Tools:
- **Canva** - Easy online design tool
- **Figma** - Professional design tool (free tier)
- **GIMP** - Free Photoshop alternative

### Quick Solutions:
1. Use app icon generators:
   - https://easyappicon.com/ (free)
   - https://appicon.co/ (free)
   - https://makeappicon.com/ (free)

2. Hire on Fiverr: $10-30 for complete icon set

### Design Tips:
- Keep it simple - icon is small on phone
- Use your brand colors
- Consider the name "UpGrade" - maybe use an arrow ↑
- Test on both light and dark backgrounds

## Placeholder Icons

For now, Expo will use default placeholder icons. Your app will work fine without custom icons during development.

## When You Need Custom Icons

You must have custom icons before:
- Publishing to App Store / Google Play
- Sharing with beta testers (for branding)
- Public launch

During development with Expo Go, default icons are fine.
