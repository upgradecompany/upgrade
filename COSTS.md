## Money-Saving Tips

1. **Start with Free Everything**
   - Use mock data
   - Test with Expo Go
   - Share via QR code
   - Wait to publish to stores

2. **Use Free Tiers**
   - eBay API: 5,000 calls/day free
   - Firebase: Generous free tier
   - Expo: Free builds available
   - GitHub: Free for small teams

3. **Cache Aggressively**
   - Store card prices locally
   - Update once per day
   - Reduce API calls by 90%

4. **Web-First Strategy**
   - Deploy as website first (FREE)
   - Test with real users
   - Gather feedback
   - Only pay for app stores when validated

5. **DIY Data Collection**
   - Manually research popular cards
   - Store in Firebase (free tier)
   - Add cards as users request
   - Build database organically

## When to Upgrade

### Upgrade to Paid Hosting When:
- You exceed free tier limits
- You have 1,000+ active users
- You need guaranteed uptime
- You need customer support

### Upgrade to Paid Data Source When:
- Users demand real-time pricing
- You're monetizing the app
- Manual data collection is too time-consuming
- You want comprehensive coverage

### Publish to App Stores When:
- You have 20+ beta testers loving it
- You've validated the concept
- You're ready to market it
- You can afford $99-124

- Need 500+ users for full-time income
